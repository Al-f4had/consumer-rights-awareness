# ConsumerShield

A Consumer Rights Awareness Website focused on consumer rights, complaint procedures, consumer protection laws and awareness quizzes in India.

## Project structure

- `index.html` — Homepage
- `rights.html` — Know Your Rights
- `complaints.html` — Complaint Guide
- `laws.html` — Laws & Consumer Protection
- `quiz.html` — Awareness Quiz
- `css/` — Shared stylesheets
- `js/` — JavaScript features
- `xml/` — Structured consumer-rights data
- `assets/images/` — Raster images
- `assets/svg/` — SVG illustrations
- `assets/icons/` — Interface icons

## Status

Initial project scaffold. Page content, styling and interactive features will be developed incrementally.
