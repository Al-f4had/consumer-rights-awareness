# Consumer Rights Awareness Website

A beginner-level HTML, CSS and JavaScript project about consumer rights in India.

## Pages
- `index.html` — Home
- `rights.html` — Six consumer rights with a search feature
- `complaints.html` — Complaint steps and a practice form with validation
- `laws.html` — Basic consumer law information and a show/hide feature
- `quiz.html` — A four-question awareness quiz

## Files
- `css/style.css` — External CSS and Flexbox navigation
- `js/script.js` — Basic JavaScript interactions
- `xml/consumer-rights.xml` — Structured consumer-rights information

## Interactive features
1. Search the consumer rights.
2. Validate the complaint practice form.
3. Show or hide additional law information.
4. Check quiz answers and calculate a score.

The complaint form is a demonstration only. It does not send or store user information.
